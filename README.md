## Установка
Тебуется Docker !!!
Выполнить следующие команды по очереди :
git clone https://github.com/arkhilya-bit/rp
cd rp
docker compose up -d
./srart

Если команду start не удалось выполнить, необходимо вручную выполнить команды
composer install
php artisan migrate --seed 
Их нужно запустить внутри контейнера rp_php.

## Задание 1
Необходимо создать веб-приложение с использованием фреймворка Laravel, которое будет использовать Redis для реализации системы ранжирования пользователей


Реализуется классом Service\Ranking
API для тестирования:
GET "localhost:8000/"            - список всех пользователей
GET "localhost:8000/rank"        - список топ 5
GET "localhost:8000/rank/{id}"   - сколько очков у пользователя id
DELETE "localhost:8000/rank/{id}"- удалить пользователя id из системы
PUT "localhost:8000/rank/{id}"   - изменить количество очков
                                    требуется тело формата:
                                    {
                                        "action": "dec",   
                                        "score": 5
                                    }
                                    action - допустимы "inc", "dec", "set"
                                    score - количество очков на операцию


## Задание 2
Система очередей для отправки уведомлении
Необходимо создать систему которое будет отправлять пуш-уведомления
Убедитесь, что уведомления отправляются асинхронно

1. Перейти на "localhost:8000/push"
2. Нажать войти (емеил и пароль уже подставлены)
3. Нажать кнопку подписаться (необходимо в браузере иметь разрешение на уведомления от Google)
4. Перейти на "localhost:8000/push/send" - отправляет уведомление всем подписавшимся пользователям

Так как класс уведомления реализует интерфейс ShouldQueue, уведомления пишутся в очередь,
а отправляться будут воркером асинхронно.
